# Nastasya Astro

Личный астрологический дашборд Настасьи.

## Что показывает

- текущее положение каждой планеты;
- знак и градус;
- дом в натальной карте;
- директное / ретроградное движение;
- следующий переход в знак;
- следующий переход в дом;
- ближайшие аспекты к натальным планетам и углам;
- трактовку текущего положения и того, что будет дальше;
- выбор любой даты.

Натальная база: 1 апреля 2002, 17:55, Кемерово. Тропический зодиак, Placidus, True Node.

Сайт работает прямо в браузере; эфемеридные расчёты выполняются через локально подключённый Astronomy Engine.
